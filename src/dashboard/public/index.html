Setup & Configuration Guide

Step-by-step instructions to connect your bot with Discord

Step 1: Discord Developer Portal

  1. Visit the Discord Developer Portal.
  2. Click New Application and give it a name (e.g., CodeX Bot).
  3. Go to the Bot tab on the left and click Add Bot (or Reset Token to reveal your token).
  4. Enable all 3 Privileged Gateway Intents:
    • Presence Intent
    • Server Members Intent
    • Message Content Intent

Step 2: Configure config.js

Open config.js in your project directory and replace the placeholders:

module.exports = {
    token: "YOUR_COPIED_BOT_TOKEN",
    clientId: "YOUR_APPLICATION_CLIENT_ID",
    dashboard: { port: 3001 }
};

Step 3: Invite the Bot

Go to OAuth2 > URL Generator, select scopes bot and applications.commands, choose Administrator permissions, and open the generated invite link.

Step 4: Run the Bot

npm run start
